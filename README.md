# KDV.ConsoleChat(PJ-03)

For Linux
TCP Chat Client

21.06.2025 Mentor's comments have been eliminated.

13.07.2025
TCP chat Server и TCP chat Client с хранением данных в СУБД MYSQL.
Реализовано:
Загрузка/сохранение параметров сервера и базы данных из файлов;
Загрузка/сохранение параметров клиента из файла;
Создание/удаление базы данных из программы;
Создание таблиц и представлений из программы (в файле databaseConstructor.h закомментированы функции, процедуры, транзакции);
Добавление/удаление пользователей;
Добавление/удаление сообщений.

Выставлена задержка на передачу данных от сервера на 0,1 секунду для готовности клиента.
